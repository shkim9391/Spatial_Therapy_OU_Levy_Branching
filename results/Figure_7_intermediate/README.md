# Figure 7 Intermediate Results

## Overview

This directory contains the intermediate data tables and final visualization files used to generate **Figure 7** of the manuscript.

**Figure 7** provides an independent biological validation of the spatial ecological framework by evaluating whether ecological summaries derived from spatial transcriptomic analyses are associated with therapy response in pediatric acute myeloid leukemia (AML).

Unlike Figures 2–6, which are based on the primary spatial transcriptomic dataset (GSE279576), Figure 7 uses an independent longitudinal pediatric AML dataset (GSE235923) to assess the clinical relevance of ecological metrics.

## Analysis summary

The analysis evaluates whether ecological quantities inferred from spatial transcriptomic data are associated with therapy response.

For each sample, the following ecological summaries are evaluated:

- OU-like ecological retention
- Lévy-like ecological escape
- Branching-like ecological amplification
- Integrated ecological risk score

Samples are grouped according to therapy-response status using metadata derived from the longitudinal pediatric AML cohort.

The analysis serves as an **independent biological validation** of the ecological framework rather than as a predictive clinical model.

## Data sources

Primary ecological framework:

- **GSE279576**
  - Spatial transcriptomics
  - Ecological context discovery
  - Opportunity scoring
  - OU-like retention
  - Lévy-like escape
  - Branching-like amplification

Therapy-response validation:

- **GSE235923**
  - Longitudinal pediatric AML single-cell RNA sequencing
  - Diagnosis, end-of-induction, and relapse samples
  - Projected onto the ecological reference learned from GSE279576

## Statistical analysis

Group comparisons were performed using nonparametric statistical tests as described in the manuscript.

Reported values include:

- sample-level ecological scores
- group summaries
- effect sizes
- P values

These analyses are intended to evaluate biological consistency of the ecological framework across independent datasets.

## Notes

Figure 7 represents an **independent validation analysis**.

No ecological contexts were inferred from GSE235923 itself. Instead, ecological information was transferred from the spatial ecological reference generated using GSE279576, allowing an independent evaluation of the biological relevance of the ecological framework.
